# 誌面ビューア + 素材ブラウザ

紙のカタログ・パンフレットの **PDF から、めくって読めるWebビューアを生成する**ツールです。
誌面上の写真・図版をクリックすると、その **印刷に使った原本ファイル（.psd / .ai など）をその場でダウンロード**できます。

👉 **デモ： [`demo/index.html`](demo/) （架空ブランドのカタログで実際に動きます）**

---

## できること

| 機能 | 内容 |
|---|---|
| 見開きページめくり | 左右キー／スライダー／ページ番号ジャンプ。表紙は単独ページ扱いも可 |
| 綴じ方向 | 洋書（左綴じ）と**和書（右綴じ）**の両対応。めくる向き・ボタンの役割・矢印キー・スライダーまで反転 |
| 誌面クリック | 画像の上にカーソルを乗せるとファイル名・寸法・容量を表示、クリックで一覧の該当行を固定選択 |
| 赤枠表示 | 「DLできる箇所」を誌面上に常時表示するトグル |
| 素材一覧 | サムネイル・拡張子・原本寸法・容量・掲載ページを一覧表示 |
| 2種類の検索 | **ファイル名**の検索と、**紙面に印刷されている文字**の検索（該当箇所へ移動して位置が光る） |
| 絞り込み | 「この見開きだけ」／ファイル種類別（種類ボタンは実データの拡張子から自動生成） |
| ダウンロード | 「元データ」＝印刷用の原本そのもの、「JPG」＝画面表示・資料貼付用の軽量版 |
| まとめてDL | チェックボックスで複数選択し、ZIPで一括ダウンロード（外部ライブラリ不使用の内蔵ZIP実装） |
| オフライン配布 | 生成物はフォルダごと配れば動作。`ツールを開く.bat` でローカルHTTP起動 |

## 仕組み

誌面のどこをクリックすると何の素材か、という当たり判定は **ページごとに1枚のPNG**で持ちます。
ピクセルの `R + (G << 8)` がそのまま素材ID。透明部分（アルファ）を持つ画像は、その形どおりに
当たり判定を作るので、リング状の製品写真なども穴の部分は反応しません。

ブラウザ側は、この判定用PNGを1度だけデコードしてページ番号ごとにキャッシュし、
表示中の見開きの前後も先読みします（めくった直後にカーソルを動かしても反応が抜けないため）。

## 使い方

```bash
pip install -r tools/requirements.txt

python3 tools/build_catalog.py \
    --pdf     カタログ.pdf \
    --out     出力フォルダ \
    --title   "総合カタログ2026" \
    --assets-dir リンク原本フォルダ \
    --links   links.csv \
    --cover
```

生成物：

```
出力フォルダ/
  index.html            ← ビューア本体（データを埋め込んだ完成品）
  pages/page-NN.jpg     ← 誌面画像
  thumbs/ light/ assets/
  ツールを開く.bat / ツールを開く.command
```

`index.html` を含むフォルダを丸ごと Web サーバーに置くか、相手に zip で渡します。

### 主なオプション

| オプション | 既定 | 説明 |
|---|---|---|
| `--pdf` | 必須 | 誌面PDF。**文字はアウトライン化せずテキストのまま**書き出すと紙面検索が効きます |
| `--out` | 必須 | 出力フォルダ |
| `--title` | `誌面ビューア` | 画面上部のタイトル |
| `--assets-dir` | なし | 原本（.psd/.ai/.eps 等）が入ったフォルダ。指定すると「元データ」が本物の原本になります |
| `--links` | なし | リンク一覧CSV（列 `page,order,filename`、いずれも1始まり） |
| `--pages` | 全ページ | 作る範囲。`21-34` や `1,5,10-12`（元PDFのページ番号・1始まり）。章単位で切り出して配るときに |
| `--binding` | `left` | 綴じ方向。**和書のカタログは `right`**（若いページが右に来て、左へめくる） |
| `--cover` | off | 先頭ページを表紙（単独ページ）として扱う |
| `--page-offset` | 0 | ページ表示名の番号のズレ補正（誌面のノンブルとPDFのページ番号が違うとき） |
| `--include-unplaced` | off | 原本フォルダにあるが誌面に配置されていないファイルも一覧に載せる |
| `--no-name-hints` | off | リンク一覧が無いとき、誌面の近くの文字（型番など）を素材名に使わない |
| `--dpi` | 150 | 誌面画像の解像度 |
| `--jpeg-quality` | 82 | 誌面画像のJPEG品質 |
| `--page-label` | `P.{n}` | ページ表示名の書式 |

### 原本との対応づけ（`--links`）

PDF の中の画像は「何番目の画像か」しか分からないため、原本ファイル名との対応表を渡します。
InDesign なら「リンク」パネルの一覧が、そのまま元ネタになります。

```csv
page,order,filename
2,1,header_band.png
2,2,structure_section.psd
2,3,ring_light_white.psd
```

* `order` は、そのページで PDF に含まれる画像の並び順（1始まり）。
* CSV を渡さない場合は、誌面ページ番号＋通し番号に、**写真の近くにある型番や見出しを付けた**
  自動命名になります（例 `p06_01_WBT-N3030SB(W).jpeg`）。型番でも検索できるので、リンク一覧が
  手に入らない他社カタログでも実用になります。無効にするには `--no-name-hints`。
* 原本フォルダにあって誌面に配置されていないファイルは、`--include-unplaced` を付けたときだけ一覧に載ります。
* サムネイルを作れない形式（.ai など）は、拡張子を大きく書いたカードを自動生成します。

### 章単位で切り出す

総合カタログのように厚い冊子は、提案する章だけを切り出して渡すと軽く・見やすくなります。

```bash
python3 tools/build_catalog.py --pdf 総合カタログ.pdf --out 出力先 \
    --title "総合カタログ2026｜リング直射光（p21-34）" --pages 21-34
```

ページ表示名は元PDFのページ番号で振られるため、抜粋しても誌面の実ページと突き合わせられます。

### 配布時の注意（`file://` 問題）

`index.html` をフォルダから直接ダブルクリックして開くと、ブラウザのセキュリティ制限で
**画像の保存とZIP一括DLが動きません**（JPGは保存されず表示されるだけになります）。
生成物に同梱される `ツールを開く.bat`（Windows）／`ツールを開く.command`（macOS・Linux）から
起動すると、公開後のWebサイトと同じ状態で開き直されます。ビューア自身もこの状態を検知して
画面上部に案内を出します。

## デモの作り直し

デモの入力（架空カタログのPDF・原本・リンク一覧）は自動生成できます（実在の製品・企業とは無関係です）。

```bash
python3 tools/make_demo.py          # demo_src/ を生成
python3 tools/build_catalog.py --pdf demo_src/demo_catalog.pdf --out demo \
    --title "アカガネ光学工業 LED照明 総合カタログ2026（デモ）" \
    --assets-dir demo_src/assets --links demo_src/links.csv --cover
```

```
tools/viewer_template.html  ビューア本体のテンプレート（HTML/CSS/JS、外部依存なし）
tools/make_demo.py          デモ用の入力一式（架空カタログ）を生成
demo/                       生成済みデモ
index.html                  （このリポジトリの別プロジェクト：思考力道場）
```
